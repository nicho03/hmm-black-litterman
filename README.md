# Regime-aware Black-Litterman: HMM + Black-Litterman asset allocation

This work is a first exploratory analysis of asset allocation using a classical combination of a
Hidden Markov Model and the Black-Litterman model. We refer to Oprisor & Kwon (2021) for further ideas.

---

## Mathematical model

### Notation

The investment universe is made of $N = 9$ ETFs quoted in USD plus USD cash. Let
$r_t \in \mathbb{R}^N$ be the vector of daily returns of the risky assets at day $t$
(log-returns in % for the models, simple returns for the backtest). Cash earns the
13-week T-bill rate $r_f$ and has zero variance.

### Hidden Markov Model

We consider an underlying HMM whose hidden states are the market regimes. With $K = 3$
regimes (crisis, neutral, calm, ordered by decreasing volatility), $\{S_t\}$ is a Markov chain
where $S_t \in \{1, \dots, K\}$ is the regime of the market at time $t$:

$$
r_t \mid S_t = k \;\sim\; \mathcal{N}(\mu_k, \Sigma_k), \qquad
A_{ij} = P(S_{t+1} = j \mid S_t = i).
$$

The filtered and one-step-ahead regime probabilities (row vectors) are

$$
p_t = P(S_t \mid r_1, \dots, r_t), \qquad
p_{t+1 \mid t} = P(S_{t+1} \mid r_1, \dots, r_t) = p_t \, A .
$$

The model requires $\mu_k$, $\Sigma_k$ and $A$, estimated with a variational-Bayes version of the
Baum-Welch (EM) algorithm, yielding $\hat\mu_k$, $\hat\Sigma_k$, $\hat A$. We also use the effective
number of days spent in each regime, $N_k = \sum_t P(S_t = k \mid r_1, \dots, r_T)$.

### Black-Litterman model

Views and prior on the vector of expected returns $\mu$:

$$
P\mu = Q + \varepsilon_v, \quad \varepsilon_v \sim \mathcal{N}(0, \Omega),
\qquad\qquad
\mu \sim \mathcal{N}\!\left(r_f + \Pi,\; \tau \Sigma_t\right),
\qquad
\Pi = \delta_{eq}\, \Sigma_{long}\, w_{ref}.
$$

We therefore need to specify $P, Q, \Omega, \tau, \Sigma_t, \Sigma_{long}, w_{ref}, \delta_{eq}$.

### Modelling the views

Views are absolute ($P = I$) and generated by the HMM, with $p = p_{t+1 \mid t}$.

- **Conditional on the regime** (`omega="conditional"`). If the next regime were known, $S_{t+1} = s$,
  the view is the estimated mean of that regime, whose estimation error is approximately
  $\mathcal{N}(0, \Sigma_s / N_s)$. We take the most likely regime $s = \arg\max_k p_k$:

$$
Q = \hat\mu_s, \qquad \Omega = \hat\Sigma_s / N_s, \qquad \Sigma_t = \hat\Sigma_s .
$$

- **Mixture over regimes** (`omega="statistical"`). The next regime is uncertain, so the view is the
  mixture mean and, by the law of total variance, $\Omega$ adds the estimation error of each regime
  mean and the dispersion of the means across regimes:

$$
Q = \sum_k p_k \hat\mu_k, \qquad
\Omega = \sum_k p_k \frac{\hat\Sigma_k}{N_k} + \sum_k p_k (\hat\mu_k - Q)(\hat\mu_k - Q)^\top .
$$

- **Idzorek** (`omega="idzorek"`), fixed confidence $c$ in the views:
  $\Omega = \alpha\, \Sigma_t$ with $\alpha = \tau (1 - c) / c$.

Except in the conditional case, $\Sigma_t$ is the covariance of the regime mixture:

$$
\Sigma_t = \sum_k p_k \hat\Sigma_k + \sum_k p_k (\hat\mu_k - Q)(\hat\mu_k - Q)^\top .
$$

### Modelling the prior

The prior follows the classical Black-Litterman reverse optimization, with the reference portfolio
$w_{ref} = 1/N$ in place of market weights. The risk aversion $\delta_{eq}$ is calibrated so that the
reference portfolio has a given Sharpe ratio (`sr_target`, default 0.35), and $\tau = 1/t$:

$$
\delta_{eq} = \frac{SR_{target}}{\sqrt{w_{ref}^\top \Sigma_{long}\, w_{ref}}}, \qquad \tau = \frac{1}{t}.
$$

$\Sigma_{long}$ is estimated on the whole history up to the last refit with the sample covariance,
Ledoit-Wolf shrinkage or the Minimum Covariance Determinant (`prior_cov`).

### Posterior

$$
M = \left[(\tau\Sigma_t)^{-1} + \Omega^{-1}\right]^{-1}, \qquad
\bar\mu = M\left[(\tau\Sigma_t)^{-1}(r_f + \Pi) + \Omega^{-1} Q\right], \qquad
\bar\Sigma = \Sigma_t + M .
$$

### Portfolio optimization

At every rebalance, with $H$ the number of days to the next rebalance, $w_{cur}$ the current
(drifted) weights and $c$ the proportional transaction cost:

$$
\max_{w}\;\; H\,\bar\mu^\top w \;-\; \frac{\delta}{2}\, H\, w^\top \bar\Sigma\, w \;-\; c\,\lVert w - w_{cur} \rVert_1
\quad \text{s.t.} \quad \mathbf{1}^\top w = 1,\;\; w \ge 0,\;\; w_i \le 0.35,\;\; \textstyle\sum_{i \in \text{equity}} w_i \le 0.70 .
$$

Cash enters with expected return $r_f$ and zero variance. The HMM + Markowitz benchmark solves the
same problem with the moments of the most likely regime, $(\hat\mu_s, \hat\Sigma_s)$, instead of $(\bar\mu, \bar\Sigma)$.

### Metrics

Computed on the daily simple returns $R_t$ of the backtest (net of costs), over $Y$ years:

| Metric | Definition |
|---|---|
| CAGR | $W_T^{1/Y} - 1$, with $W_t = \prod_{s \le t}(1 + R_s)$ |
| Vol | $\sqrt{252}\; \mathrm{std}(R_t)$ |
| Sharpe | $\sqrt{252}\; \mathrm{mean}(R_t - r_{f,t}) \,/\, \mathrm{std}(R_t - r_{f,t})$ |
| MaxDD | $\min_t \left(W_t / \max_{s \le t} W_s - 1\right)$ |
| Calmar | CAGR / \|MaxDD\| |
| VaR 99% | $-q_{0.01}(R_t)$, historical daily |
| ES 99% | $-\mathrm{mean}\left(R_t \mid R_t \le q_{0.01}\right)$, historical daily |
| Turnover/yr | $\sum_{\text{rebalances}} \lVert w_{new} - w_{cur} \rVert_1 \,/\, Y$ |
| Costs/yr | transaction costs paid, as a fraction of wealth per year |

Differences in Sharpe ratio are tested with a paired circular block bootstrap (block lengths of 20,
60 and 120 days, 2000 replicates), with Holm correction for multiple comparisons.

## Installation

Python 3.9 or later (tested with Python 3.13).

```bash
pip install -r requirements.txt
```

## Usage

Run the main backtest from the repository folder (or with the Run button of an IDE):

```bash
python main.py
```

It takes roughly 5-10 minutes, most of which is spent fitting the HMM. The sensitivity analysis on
the prior Sharpe ratio (30 backtests) takes roughly 10-15 minutes:

```bash
python sr_sensitivity.py
```

Plots can be redrawn from the saved CSV files without rerunning the backtests, with
`replot_bootstrap()` in `main.py` and `replot()` in `sr_sensitivity.py`.

### Configuration

All settings are constants at the top of `main.py`:

| Constant | Default | Meaning |
|---|---|---|
| `COMMON["n_train"]` | 1260 | days of history before the first rebalance (5 years) |
| `COMMON["rebalance_every"]` | 20 | days between rebalances |
| `COMMON["risk_aversion"]` | 0.05 | $\delta$ in daily % units (≈ 5 in decimal units) |
| `COMMON["spread_bps"]` | 10 | proportional transaction cost, in basis points |
| `CONSTRAINTS` | max 35% per asset, equity ≤ 70% | extra constraints of the optimized strategies |
| `OMEGAS`, `PRIOR_COVS` | 3 + 3 options | Black-Litterman configurations to run |
| `MAIN_PRIOR` | `"sample"` | prior covariance used in the performance and weights plots |
| `SEED`, `N_RESTARTS` | 123, 5 | HMM random seed and number of starts at every fit |
| `BLOCKS`, `N_BOOT` | (20, 60, 120), 2000 | bootstrap block lengths (days) and replicates |

## Data

- **Assets:** SPY, EFA, EEM (equity), TLT, IEF, TIP (Treasury), LQD (corporate), GLD, DBC (real assets),
  daily adjusted prices from Yahoo Finance via `yfinance`, from March 2006.
- **Risk-free rate:** 13-week T-bill (`^IRX`); the cash return of day $t$ uses the rate of day $t-1$.
- Data are downloaded once and cached in `data/`, so every run uses the same numbers.
  Delete the folder to download fresh data.

## Backtest conventions

- **Walk-forward, no look-ahead:** every decision at day $t$ uses only data up to $t-1$. The HMM is
  refitted once a year on an expanding window; regime probabilities are updated at every rebalance.
- **Benchmarks:** S&P 500 (SPY) and 60/40 (SPY/IEF) are buy-and-hold; 1/N is rebalanced to equal
  weights every `rebalance_every` days.
- **Costs and drift:** between rebalances weights drift with prices; at each rebalance the
  proportional cost is charged on the turnover $\lVert w_{new} - w_{cur} \rVert_1$.
- **Shared regime model:** all HMM strategies share one `RegimeModel`, which is fitted once and
  cached. Strategies sharing it must use the same calendar; the code raises an error otherwise.
- **Multistart:** at every refit the HMM is estimated from 5 starting points (including a warm start
  from the previous fit) and the fit with the highest ELBO is kept. The prior on the regime means is
  set to zero so that the ELBOs of the candidates are comparable.
